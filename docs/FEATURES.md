## 缓存和数据

歌词按服务器、用户、歌曲隔离；取得的歌词缓存 30 天，确认无歌词缓存 6 小时，网络错误仅短暂冷却。切换译文显示、调时、改字号及封面配色变化不会重新请求歌词；缓存过期且网络失败会保留旧歌词。显示列表过滤空 cue，间奏期间保持前一句高亮，可见歌词的长按时间仍取原 cue；无译文时禁用翻译图标并提供无障碍说明。下载歌曲会预取歌词；编辑保存为本地覆盖，不上传或改写 Emby 标签。自动缓存必须收到完整、可验证的音频响应；局部 Range、起始位置非零的转码流、截断响应不会变成离线文件。

封面磁盘预算 256 MB：有标签的图片保存 30 天、无标签 7 天、确定缺图 6 小时；网络故障不写入缺图记录，有旧图则保留。列表磁盘预算 64 MB / 512 页，正常命中 24 小时不请求；24 小时至 30 天先用旧页并后台更新，下次读取使用更新结果，失败冷却 60 秒。手动刷新、收藏与歌单写操作会使该账号列表缓存失效。页面内保留最近 12 个查询的列表和滚动位置。以上预算独立于音频上限。

离线歌曲无需有效令牌即可播放，但必须已有账号目录及完整下载。账号之间不能互读下载。退出账号会停止播放并清除会话 / 队列，下载文件保留在私有存储，同账号重新登录后可见。自动缓存可清理，手动下载由用户移除；未完成下载和失败记录在进程结束后需重新发起。

自动缓存容量按所有账号合计，文件与曲库任务进度按账号隔离。列表标记通过完整音频索引就地更新，不重新请求封面或列表。只在开始 / 恢复播放时更新歌曲的最近播放时间；未听过的新版预缓存歌曲优先被替换，旧版已有文件沿用原有时间作为初始顺序。队列和整库预取用剩余配额，只有正播放的音频入缓存或下调上限会主动淘汰旧文件。整库任务在上限或剩余磁盘空间不足时暂停，明确恢复后从断点继续。离线页「已下载」列的是手动保留的下载，自动缓存可从原列表和队列播放。

不同播放档位分别保存，继续识别旧版原始音频和 192 kbps 文件。在线播放优先匹配选择的档位；已有手动下载或连接失败时，可以复用其他档位的完整副本。后台预取仍跳过已有完整音频的歌曲。曲库从批量返回的媒体字段提取标识，升级前的列表快照离线可用，联网后后台更新。

## 实际限制

- 原生 MediaPlayer 的解码能力取决于固件；原格式失败可回退 MP3 转码，服务端账号需允许转码。在线缓存是完整流缓存，不保证每次尚未播完就能离线。
- 均衡器、低音增强的可用性由固件和输出设备决定。部分设备的低音增强只有开关。档位是向 Emby 请求的转码目标；列表上源文件的 SQ / HQ 等标识与输出码率无关。
- Emby 歌单写操作、删除和元数据修改遵循服务端权限。普通测试账号没有媒体删除权限，权限不足不会被当成登录过期。
- 逐字高亮要求 LRC 增强时间标签或 API 单词时间；纯文本可手动浏览。自动翻译需要用户自己的可用翻译服务，没有预置免费服务。
- 独立译文按时间轴在 1.5 秒内对齐；无时间轴译文要求行数一致。未标语言、同书写系统的双语行无法可靠自动拆分，可通过独立译文编辑器明确标注。
- 悬浮歌词需要系统允许悬浮窗；离开应用且正在播放才显示。安装更新仍需系统确认，固件若禁用安装器则需侧载。
- 当前 release 不可调试但沿用已有测试签名以便覆盖升级。0.1.0 没有更新入口，首次需手动安装当前版本。
- 超大连续队列会丢弃较早历史以控制内存；当前及最近历史保留。全库随机按打乱的页遍历，避免一次拉取整库。

## 后续扩展与实车验证

多服务器快速切换、设置导入导出、第三方封面匹配、ReplayGain、无缝播放保证、交叉淡入淡出、CarPlay / Android Auto 尚未实现。

CS11 私有方向盘广播、签名白名单、自启动、锁车休眠与唤醒仍需实车验证；模拟器可验证标准媒体键和常见包名入口，不能代替固件验证。
